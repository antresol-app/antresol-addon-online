# Расширение «Онлайн» для Antresol

[English](README.md)

Смотреть фильмы и сериалы без загрузки: на странице фильма в
[Antresol](https://antresol-app.github.io/antresol/ru/) появляется способ **Смотреть ▾ → Онлайн**
с источниками, озвучками и сериями. Прогресс сохраняется так же, как для медиатеки.
Только для взрослых профилей.

## Установка

1. В Antresol: **Настройки → Сервер → Расширения → Добавить расширение**, вставьте
   `https://github.com/antresol-app/antresol-addon-online`, **Проверить**, **Установить**.
2. Добавьте Lampac — вспомогательную службу (ниже).
3. Проверьте: **Настройки → Сервер → Онлайн → Состояние источников** пишет, что служба отвечает.

## Lampac — вспомогательная служба

Потоки ищет [Lampac](https://github.com/lampac-nextgen/lampac) — программа, которая работает
рядом с сервером. Добавьте её в тот же `compose.yml`, что и Antresol, под `services:`, рядом с
`antresol`, без `ports:`:

```yaml
services:
  antresol:
    # ... как было

  lampac:
    image: ghcr.io/lampac-nextgen/lampac:1.84.3
    restart: unless-stopped
```

Выполните `docker compose up -d`. В течение полуминуты расширение найдёт Lampac по имени службы,
`http://lampac:9118`: вводить ничего не нужно, перезапускать тоже.

Состояние видно в **Настройки → Сервер → Онлайн**. Пока Lampac не найден, страница
**Состояние источников** показывает этот же блок, а способ «Онлайн» скрыт.

### Lampac в другом месте

Если Lampac уже работает у вас в сети или его `accsdb` требует id пользователя, задайте адрес в
`.env` сервера Antresol и выполните `docker compose up -d`:

```sh
ANTRESOL_ONLINE_LAMPAC_URL=http://<хост>:9118/?uid=<id>
```

Этот адрес главнее найденного. В приложении он не показывается, в журнал попадают только схема и
хост. Так же поступите, если Antresol запущен не в Docker.

## Где это в приложении

- Страница фильма или сериала: **Смотреть ▾ → Онлайн** — выберите источник и озвучку; у сериалов —
  сезоны и серии.
- **Настройки → Сервер → Онлайн** — включить или выключить способ, состояние источников.
- ТВ-каналы могут показывать найденное онлайн между фильмами из медиатеки.
