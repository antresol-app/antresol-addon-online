# Расширение «Онлайн» для Antresol

[English](README.md)

Смотреть фильмы и сериалы без загрузки: на странице фильма в
[Antresol](https://antresol-app.github.io/antresol/ru/) появляется способ **Смотреть ▾ → Онлайн**
с источниками, озвучками и сериями. Прогресс сохраняется так же, как для медиатеки.
Только для взрослых профилей.

## Установка

1. В Antresol: **Настройки → Сервер → Расширения → Добавить расширение**, вставьте
   `https://github.com/antresol-app/antresol-addon-online`, **Проверить**, **Установить**.
2. Подключите Lampac — три шага [ниже](#подключение-lampac).
3. Проверьте: **Настройки → Сервер → Онлайн → Состояние источников** пишет, что служба отвечает.

## Подключение Lampac

Потоки ищет [Lampac](https://github.com/lampac-nextgen/lampac) — отдельная программа рядом с
сервером. Подключение — три шага; всё, кроме первого, делается в приложении:
**Настройки → Сервер → Онлайн**, блок **Подключение к Lampac**.

### Шаг 1. Запустите Lampac

Если Lampac у вас уже работает (в сети, на другой машине) — пропустите шаг. Иначе добавьте его в
тот же `compose.yml`, что и Antresol, под `services:`, без `ports:`, и выполните
`docker compose up -d`:

```yaml
services:
  antresol:
    # ... как было

  lampac:
    image: ghcr.io/lampac-nextgen/lampac:1.84.3
    restart: unless-stopped
```

Расширение само найдёт его по имени службы, `http://lampac:9118`, в течение полуминуты.

### Шаг 2. Адрес и вход

В **Подключение к Lampac**:

- **Адрес Lampac** — уже заполнен, если служба найдена по `compose.yml`. Если Lampac в другом
  месте, впишите его адрес, например `http://192.0.2.10:9118`.
- **Вход** — нужен, если в Lampac включены аккаунты (`accsdb` в его `init.conf`; без входа он
  отвечает «нет доступа»). Выберите, как Lampac вас узнаёт, и впишите значение:
  - **Идентификатор (uid)** — id из списка `accsdb.accounts` / `users.json` Lampac (то, что
    Lampa спрашивает при входе);
  - **Почта аккаунта** (`account_email`), **Токен** (`token`) или **MAC-адрес приставки**
    (`box_mac`) — если аккаунт заведён под ними;
  - **Общий пароль** (`accsdb.shared_passwd`) — расширение само заведёт себе id этим паролем,
    как это делает Lampa, и продлит его, когда срок (`shared_daytime`) выйдет.

  Значение хранится в базе расширения, добавляется к каждому запросу к Lampac и нигде не
  показывается, в журнал попадают только схема и хост.

### Шаг 3. Проверьте и сохраните

Нажмите **Проверить**: расширение сделает настоящий запрос к Lampac с этим адресом и входом и
скажет одно из трёх — **вход принят** (и сколько источников), **авторизация не принята**
(значение не то) или **Lampac не отвечает** (адрес не тот или служба не запущена). Потом
**Сохранить** — подключение применяется сразу, без перезапуска. Ниже появится список источников
Lampac: их можно выключать и менять порядок.

### Через переменную сервера

Адрес можно задать и в `.env` сервера Antresol (так же — если Antresol запущен не в Docker),
затем `docker compose up -d`:

```sh
ANTRESOL_ONLINE_LAMPAC_URL=http://<хост>:9118/?uid=<id>
```

Переменная главнее адреса из настроек; вход из настроек к ней тоже добавляется.

## Где это в приложении

- Страница фильма или сериала: **Смотреть ▾ → Онлайн** — выберите источник и озвучку; у сериалов —
  сезоны и серии.
- **Настройки → Сервер → Онлайн** — включить или выключить способ, подключение к Lampac (адрес,
  вход, проверка), источники Lampac, их состояние.
- ТВ-каналы могут показывать найденное онлайн между фильмами из медиатеки.
